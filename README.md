# Google Maps Domain Search

Небольшое Streamlit-приложение для поиска домена в Google Maps через
[DataForSEO SERP API](https://docs.dataforseo.com/v3/serp/google/maps/live/advanced/).

## Локальный запуск

### Быстрый запуск в Windows

Запустите `run.bat` двойным щелчком. Скрипт автоматически:

- найдёт Python 3;
- создаст виртуальное окружение `.venv`;
- установит зависимости, если они ещё не установлены;
- выберет свободный локальный порт;
- запустит Streamlit и откроет приложение в браузере.

При следующих запусках готовое окружение будет использовано повторно.

### Ручной запуск

1. Создайте виртуальное окружение и установите зависимости:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

2. Скопируйте `.streamlit/secrets.toml.example` в
   `.streamlit/secrets.toml` и укажите данные DataForSEO. Этот файл исключён
   из Git.

3. Запустите приложение:

   ```powershell
   streamlit run app.py
   ```

Логин и пароль также можно ввести непосредственно в боковой панели.

## Деплой на Streamlit Community Cloud

1. Загрузите репозиторий на GitHub, не добавляя `secrets.toml`.
2. На [share.streamlit.io](https://share.streamlit.io/) создайте приложение и
   выберите `app.py` как Main file path.
3. В **Advanced settings → Secrets** добавьте:

   ```toml
   DATAFORSEO_LOGIN = "your_login"
   DATAFORSEO_PASSWORD = "your_password"
   ```

После деплоя приложение для каждого домена покажет однозначный результат `ДА` или
`НЕТ`. При совпадении домена сайта в карточке будет доступна прямая ссылка на
карточку Google Maps, сформированная по `place_id`. Результаты можно скачать в CSV,
а исходный JSON-ответ API — открыть для диагностики.

`НЕТ` означает, что точного совпадения домена не найдено среди результатов,
проверенных с выбранной глубиной. Это не доказывает отсутствие карточки за
пределами выданных Google Maps результатов.

После проверки приложение показывает фактическую стоимость всех выполненных
запросов в USD. Значение берётся из поля `cost` ответа DataForSEO; в раскрывающемся
блоке доступна разбивка стоимости по доменам.

До запуска приложение автоматически показывает предварительную стоимость. В
расчёте учитываются уникальные домены, выбранная глубина и записи, уже имеющиеся в
базе. Проверка из базы стоит `$0`; Live-запрос оценивается по актуальной ставке
аккаунта за каждый блок до 100 результатов. Фактическая сумма после выполнения
может быть меньше предварительной из-за возврата за неполученные результаты.

В боковой панели отображается текущий баланс DataForSEO и кнопка его обновления.
Данные запрашиваются через бесплатный endpoint `/v3/appendix/user_data` и
кэшируются на 60 секунд, поэтому ввод доменов не создаёт лишних обращений к API.

## База проверок

Результаты автоматически сохраняются в локальной SQLite-базе
`data/checks.sqlite3`. Ключ записи включает домен, локацию, язык, глубину и режим
поиска по области. При повторном запросе с теми же параметрами приложение отдаёт
сохранённый результат без обращения к платному API и отмечает источник в таблице.

Чтобы выполнить новую проверку и заменить запись, включите флажок **Обновить
сохранённые результаты через API**. Если обновление завершится ошибкой, приложение
сохранит и покажет последнюю успешную запись из базы.

На Streamlit Community Cloud локальные файлы могут быть удалены при перезапуске
или повторном деплое приложения. Для постоянного облачного хранения SQLite следует
заменить на внешнюю базу данных, например PostgreSQL.

В поле доменов можно вставить до 5000 значений: по одному на строку либо через
запятую, точку с запятой или пробел. Повторяющиеся домены удаляются автоматически.
Live endpoint DataForSEO допускает только одну задачу в API-вызове, поэтому каждый
домен отправляется отдельным запросом и тарифицируется отдельно. Приложение
обрабатывает до 5000 доменов за запуск пакетами по 100 и одновременно выполняет
не более пяти API-запросов. Во время работы отображаются общий прогресс, номер
текущего пакета и последний обработанный домен.

Локация и язык выбираются из поисковых выпадающих списков. Чтобы быстро найти
значение, начните вводить название страны или языка на русском либо английском.
Выбранные локация и язык входят в ключ базы, поэтому результаты разных гео не
смешиваются.
